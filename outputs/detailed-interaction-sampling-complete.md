# Detailed interaction sampling — complete

The six reference websites now have implementation-level signature motion manifests.

## What was measured

| Reference | Completed sample |
|---|---|
| Nothin’ | 21-point Works Flip/parallax sequence plus responsive fallback |
| Voyeur Vérité | 21-point pinned history sequence plus tablet/mobile geometry |
| Scheme Engine | five WebGL journey checkpoints, responsive canvas checks and source behavior map |
| House of Corto | two-axis inertial world, five frames, layered hover and mobile input response |
| Jesko Jets | 21-point hero, 21-point aircraft handoff, accordion/media click and responsive asset swap |
| a-lign studio | 21-point pinned process plus tablet/mobile compact-row branch |

## Most important architecture decisions

- Noth’s letters, cards, image parallax and cursor become separate modules with a shared section trigger.
- Voyeur’s history becomes a configurable pinned-steps module with an optional SVG-morph adapter.
- Scheme’s WebGL browser stays an independent advanced package.
- Corto’s gallery uses a viewport/world engine, not ScrollTrigger.
- Jesko’s reusable pieces are the zoom-apart hero and accordion/media system; the aircraft sequence is a composition recipe.
- a-lign uses one content model with two renderers: pinned process on desktop and compact rows on smaller screens.
