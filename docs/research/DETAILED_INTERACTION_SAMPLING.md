## Normalized sampling rule

High-salience DOM/GSAP sequences were sampled at `0, .05 … 1`. Canvas or input-path-dependent systems were captured at stable visual checkpoints and supplemented by executable source inspection. Tablet/mobile checks used entry, midpoint and exit where normal document scrolling applied, plus input-state checks for the transform world.

## Cross-site conclusions

1. A single animation cannot own a whole section merely because the visuals overlap. Noth’s Flip, card parallax, image parallax and cursor are separate systems sharing one section.
2. Responsive behavior is often a different interaction model, not a scaled copy. Noth drops Flip/pinning; a-lign swaps pinned cards for compact rows.
3. Canvas/WebGL systems need their own render and resource lifecycle. Scheme’s browser and a-lign’s frame sequences should not be hidden inside generic GSAP modules.
4. Fixed internal worlds are not ScrollTrigger timelines. Corto needs normalized wheel/touch input, inertia and world wrapping.
5. Site-specific compositions can still be assembled from reusable primitives. Jesko’s aircraft piece combines sticky layout, scaling, CSS masks and staged media handoff.

## Implementation gate completed

The production scaffold, main module catalogue and six isolated advanced packages are implemented. The advanced status matrix records the boundary between completed reusable behavior and the approved project media/art direction still required for a source-specific build.
