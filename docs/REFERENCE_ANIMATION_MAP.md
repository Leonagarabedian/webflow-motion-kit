# Six-reference animation map

Purpose: reconnect the reusable toolkit to the six source pages that motivated it. This file records only mappings already supported by the repository research. It does not claim pixel-identical reproduction.

| Reference | Observed / researched interaction | Current reusable piece | Current level | What stays composition-specific |
|---|---|---|---|---|
| Noth’ (`noth.in`) | Works relocation, portfolio/media parallax, cursor; additional fluid/velocity studies | `flip-relocation`, `parallax`, `cursor`, Advanced `fluid-canvas`, Advanced `velocity-effects` | primitives + components | Exact Works section choreography, art direction and layer composition |
| Voyeur Vérité (`voyeurverite.com`) | Pinned history, SVG morph, theme/navigation handoff | `pinned-steps`, `morph-narrative`, `theme-switch` | components + primitive | Exact history content, masks/path pairs, section timing and conclusion/footer handoff |
| Scheme Engine (`schemeengine.com`) | Fixed/spatial WebGL work journey | Advanced `webgl-work-browser` | composition | CMS media, camera/layout art direction, categories, routes and transition contract |
| House of Corto (`houseofcorto.com`) | Infinite transform-driven product world and layered product hover | Advanced `infinite-product-world`, `stacked-image-hover` | composition + component | Product tile system, world dimensions and final inertia/layout tuning |
| Jesko Jets (`jeskojets.com`) | Hero zoom-apart, aircraft-to-blueprint handoff, synchronized benefits accordion | Advanced `aircraft-scroll-story`, `accordion-media` | composition + component | Aircraft/blueprint/globe/spec sequence is a site recipe, not a primitive |
| a-lign (`a-lign.studio`) | Pinned process narrative and frame/image sequence | `pinned-steps`, Advanced `image-sequence` | component | Exact process timing, compact responsive branch, optimized frame media and overlay copy |

## How to use this map

For each Branda animation, first identify which reference behavior it is borrowing. Then choose the smallest existing primitive/component that reproduces the mechanism. Only create a page composition when multiple reusable pieces must be sequenced together.
